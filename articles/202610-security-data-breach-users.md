## はじめに

「お客様の個人情報が流出した可能性があります。申し訳ございません。」

こんなメールを受け取ったことはありませんか。私自身、ここしばらくのあいだに、いくつかの会社から「メールアドレスやお名前が流出しました」というお詫びのメールが届きました。最初は驚きましたが、何通か続くうちに「またか」と感じてしまっている自分に気づいて、それはそれで少し怖くなりました。

2026年9月には、カーシェアサービス「タイムズカー」のWebシステムが不正アクセスを受け、約660万アカウントの情報が流出したことが公表されました。そのうち約160万アカウントでは、運転免許証の画像などの本人確認書類まで含まれていたとされています。

こういうとき、よく言われるのは「パスワードを使い回さない」「二段階認証を設定する」といった対策です。もちろん大切なのですが、この記事を読んでくださっている方の多くは、すでに済ませているのではないでしょうか。そして、それをやっていても、お詫びのメールは届きますよね。

本記事では、いま起きていることを数字で確かめたうえで、基本の対策は済ませている前提で、利用者がその次にできることを、7つに絞って一緒に整理していきます。

## 対象者

- 「個人情報が流出しました」というお詫びのメールを受け取ったことがある方
- パスワードマネージャーや二段階認証は使っていて、その次に何をすればいいのかを知りたい方
- 本人確認書類の画像を、オンラインで提出したことがある方
- 家族や身近な人に、基本の次にできる対策を伝えたい方

## いま、何が起きているのか

東京商工リサーチが10月7日に公表した集計では、上場企業とその子会社による100万件以上の漏えいは、10月5日時点ですでに10件に達していました。2025年は1年間で6件でしたから、その時点ですでに上回っています。表にある事例のいくつかは、その集計のあとに公表されたものです。

https://www.tsr-net.co.jp/data/detail/1203305_1527.html

10月9日には、金融庁と経済産業省がそれぞれ事業者に向けて注意喚起を出し、国家サイバー統括室やIPAなども同じ時期に呼びかけを行っています。報道の中では、専門家が「日本のセキュリティでは史上最悪の被害」と表現したことも伝えられました。

https://www.fsa.go.jp/news/r8/sonota/20261009/20261009.html

### 原因から分かること

表の右の列を見ると、外部からの不正アクセスが中心であることが分かります。加えて、委託先のサーバーやPC、利用していたクラウド基盤といった、その会社の外側から影響が及んだ例が目立ちます。経済産業省の注意喚起でも、サプライチェーンを経由した侵害が挙げられていました。AIの活用によって攻撃の効率が上がっている、という指摘もあります。

使う側にとって、ここは大事なところだと思います。私たちが情報を預けている相手は、登録した会社だけではありません。その会社が業務を任せている委託先や、裏側で使っているサービスにも、情報は渡っています。平たく言えば、「信頼できる会社にしか登録していないから大丈夫」とは言い切れない、ということです。

### 退会していても、対象になる

タイムズカーの件では、すでに退会した方や、入会を途中でやめた方の情報まで含まれていました。日本経済新聞の報道によると、同社は法人税法に基づくものとして、退会後も7年間は個人情報を保管していたと説明しています。

https://share.timescar.jp/news/2026/0928/1815.html

「もう使っていないから関係ない」とも、言い切れないわけです。

### 流出した情報は、どう使われるのか

| 流出した情報 | 起きうること |
| --- | --- |
| メールアドレス・氏名 | 会社を装ったフィッシングメールやSMSが届く |
| メールアドレスとパスワード | 同じ組み合わせを使っている別のサービスへの不正ログイン |
| 電話番号・住所・生年月日 | 本人しか知らないはずの情報を添えた、もっともらしい詐欺の連絡 |
| 本人確認書類の画像 | 画像を送る方式の本人確認を通して、なりすましで契約や口座開設をされるおそれ |

やっかいなのは、複数の流出が重なることです。ある会社からは名前とメールアドレス、別の会社からは住所と電話番号、というように、ばらばらに流出した情報が組み合わさると、1件ずつよりもずっと精度の高い「あなたの情報」になってしまいます。

流出そのものは、私たちには止められません。ただ、預けている情報の量と、流出したあとに使われにくくする仕組みは、手元で変えられます。ここからの7つは、その2つに絞ったものです。

## 利用者ができる対策7選

パスワードマネージャーで使い回しをなくすことと、主要なサービスに二段階認証を設定することは、済んでいる前提で進めます。まだの方は、そこから始めるのがいちばん効果的です。

最初の1は、預けていない情報は流出しないという、いちばん根本の対策です。2から6は、優先度が高く、手を付けやすいものから順に並べました。7だけは少し性格が違い、本人確認書類の画像が流出したときの備えとして最後に置いています。

### 1. 退会で終わらせず、消去まで依頼する

使っていないアカウントの退会は、よく挙げられる対策です。ただ、今回の件で分かったのは、退会しても情報は残ることがある、という点でした。そこで、退会に加えて次のことも行います。

- 退会の前に、登録している住所、クレジットカード、本人確認書類を、自分で削除できる画面があれば先に消しておく
- プライバシーポリシーで、退会後の保管期間と、その理由を確認する
- 問い合わせ窓口から、保有している個人データの消去を依頼する

個人情報保護法の第35条では、事業者がその情報を利用する必要がなくなった場合や、漏えいが起きた場合などに、本人が利用停止や消去を請求できると定められています。法令で保管が義務づけられている情報は対象外になりますが、「法令上必要なもの以外は消してください」と伝えることには意味があると思います。

あわせて見直しておきたいのが、ソーシャルログインの連携です。Google、Apple、LINEなどのアカウント設定には、連携しているサービスの一覧があります。タイムズカーの件でも、連携サービスのIDが流出した情報に含まれていました。使っていないサービスとの連携は、ここで解除しておくと安心です。

### 2. パスワードマネージャーの自動入力で、偽サイトに気づく

大きな流出のあとには、それに便乗した偽のお詫びメールが出回ります。しかも今回は、氏名や住所といった本物の情報が添えられているかもしれません。文面の不自然さで見分けるのは、だんだん難しくなっていくと思っておいたほうがよさそうです。

そこで、人の目ではなく、仕組みに見分けてもらいます。パスワードマネージャーの自動入力は、保存したときのドメインと一致するサイトでしか候補を出しません。

- ログインは、手で入力せずに自動入力で行う
- 候補が出てこなかったら、「入力欄の認識に失敗したのかな」と手でコピーする前に、まずURLを疑う
- メールやSMSの中のリンクからはログインせず、ブックマークから開く

本物のお詫びメールであっても、公式サイトのお知らせから確かめて困ることはありません。電話の場合も、いったん切って、公式サイトに載っている番号にかけ直すのが確実です。

### 3. 流出を通知で受け取れるようにする

Have I Been Pwned でメールアドレスを検索するという方法があります。ただ、思い出したときに検索するだけでは、次の流出には気づけません。

https://haveibeenpwned.com/

- Have I Been Pwned の通知機能にメールアドレスを登録して、新しい流出に含まれたときに知らせてもらう
- 独自ドメインを使っている場合は、ドメイン単位での検索と通知を設定する
- パスワードマネージャーの流出チェック機能（1Password の Watchtower、Appleの「セキュリティに関する勧告」、Google のパスワード チェックアップなど）を有効にしておく

あとの6で紹介するように、サービスごとにメールアドレスを分けておくと、ここでも役に立ちます。通知が届いたアドレスを見れば、どのサービスの話なのかがすぐに分かるからです。

:::message
国内だけで公表された流出は、こうしたサービスに載らないこともあります。通知がないことは、流出していないことの証明にはなりません。各社の公式発表とあわせて見るのがおすすめです。
:::

### 4. パスキーを設定して、アカウントの復旧方法も確認する

二段階認証を設定していても、SMSやメールで届くコードは、偽のサイトに入力させられてしまえば突破されます。パスキーは、登録したサイトのドメインでしか使えない仕組みなので、見た目がそっくりな偽サイトでは、そもそも認証が始まりません。

- 対応しているサービスでは、パスキーを登録する
- パスキーを登録したら、SMSによる認証を外せないか確認する
- 対応していないサービスでは、SMSよりも認証アプリを選ぶ

そして、見落としやすいのが復旧の経路です。パスキーを設定していても、「パスワードを忘れた方はこちら」から、メール1通でパスワードを再設定できるのであれば、守りの強さはそのメールアカウントと同じになります。

- パスワード再設定のメールが届くメールアカウントを、いちばん強い認証で守る
- バックアップコードを、パスワードマネージャーとは別の場所にも控えておく
- 「秘密の質問」は、事実ではなくランダムな文字列を答えにして、パスワードマネージャーに保存する

生年月日や出身地のように、流出した情報から推測できる答えを設定していないか、一度確かめておくだけでも、ずいぶん安心できると思います。

### 5. 本人確認は、画像を送らない方式を選ぶ

今回いちばん重かったのは、本人確認書類の画像が流出したことでした。パスワードは変えられますが、顔写真と住所と生年月日は変えられません。

オンラインの本人確認（eKYC）には、大きく分けて2つの方式があります。

| 方式 | 事業者の手元に残るもの |
| --- | --- |
| 本人確認書類と顔を撮影して送る | 書類と顔の画像 |
| マイナンバーカードなどのICチップをスマートフォンで読み取る | 画像ではなく、ICチップから読み取った情報と電子的な検証の結果 |

金融機関などの本人確認では、画像を送る方式を2027年4月1日に廃止し、ICチップの読み取りに原則として一本化する方針が示されています。10月9日の金融庁の注意喚起では、その日を待たずに、できるだけ早く移行するよう求められました。

私たちの側でできることは、次のようなことだと思います。

- 両方の方式が選べるサービスでは、ICチップを読み取る方式を選ぶ
- 画像の提出が必要なサービスは、登録の前に「本当にここに預けたいか」を一度考える
- すでに提出したサービスで、確認が済んだあとも画像が保管されているのかを、プライバシーポリシーや問い合わせで確認する

本人確認が必要なサービスすべてを避けるのは現実的ではありません。それでも、選べる場面で画像を残さない方式を選んでいくだけでも、流出したときの被害はずいぶん小さくなると思います。

### 6. サービスごとにメールアドレスを分ける

パスワードはサービスごとに変えていても、メールアドレスは同じものを使っている方が多いのではないでしょうか。ログインIDが共通だと、流出した情報どうしを結びつける「鍵」になってしまいます。

| 方法 | 特徴 |
| --- | --- |
| iCloud+ の「メールを非公開」 | サービスごとにランダムなアドレスを発行し、本来のアドレスに転送する |
| メールエイリアスの専用サービス（SimpleLogin、addy.io など） | 発行と停止を自由にでき、独自ドメインも使える |
| Gmail の `+` 付きアドレス | 手軽に始められる。ただし `+` 以降を取り除けば元のアドレスが分かる |
| 独自ドメインのキャッチオール | `サービス名@自分のドメイン` を無制限に使える |

こうしておくと、うれしい点が3つあります。

- 不審なメールが届いたとき、宛先のアドレスを見れば、どのサービスから流出したのかが分かる
- 流出したアドレスだけを停止すれば、そこに届くフィッシングメールを止められる
- 別のサービスで同じIDを試されても、そもそも一致しない

全部のサービスで一度に切り替えるのは大変なので、これから新しく登録するものから始めるのがおすすめです。

### 7. 信用情報機関の本人申告と、カードの利用通知を設定する

本人確認書類の画像が流出した場合、心配なのは、自分の名前で契約や借り入れをされることです。ここには、あまり知られていない仕組みがあります。

クレジットカードやローンの申し込みがあると、会社は審査のために、信用情報機関に登録されている情報を照会します。国内には3つの信用情報機関があり、どこも「本人申告」という制度を用意しています。平たく言えば、「私の本人確認書類は流出しているので、私の名前で申し込みが来たら注意してください」というメモを、自分の信用情報に付けておける仕組みです。

| 機関 | 本人確認書類の画像が流出した場合の扱い | 公式の案内 |
| --- | --- | --- |
| CIC | 本人申告（紛失盗難）の手続きで登録でき、会員会社への注意喚起になると案内されている | [本人確認書類の画像が流出した場合、どうすればよいですか？](https://www.cic.co.jp/faq/detail/3844.html) |
| JICC | 現物は手元にあり画像などの情報が流出した場合は、「名義の悪用防止」の本人申告コメントを登録できる | [運転免許証等の現物は手元にあるが画像など情報が流出してしまった場合](https://www.jicc.co.jp/faq/detail/a095i000000LtgMAAS) |
| 全国銀行個人信用情報センター | 本人確認書類の紛失、盗難、漏えいなどで名義を使われる可能性がある場合に、本人申告情報を登録できる | [本人申告の手続き](https://www.zenginkyo.or.jp/pcic/return/) |

知っておきたい点が3つあります。

- 契約を自動的に止める仕組みではありません。会員会社が審査のときに参照する注意書きで、CICも[効力を保証するものではない](https://www.cic.co.jp/mydata/declaration/index.html)と明記しています
- 機関ごとに加盟している会社が異なります。JICCは、[それぞれの信用情報機関に登録することをおすすめします](https://www.jicc.co.jp/faq/detail/a095i000000LtgOAAS)と案内しています
- 受け付けの条件、手数料、申込方法は機関ごとに異なります。申し込みの前に、上の表の公式ページで最新の案内を確認してください

:::message
今回の一連の流出を受けて申し込みが集中しており、CICは[郵送の手続きに時間を要している](https://www.cic.co.jp/news/info/2026/10/e98fb88d2907c516278679029326b8c047f4b469.html)こと、JICCは[開示と本人申告コメントの登録が遅延している](https://www.jicc.co.jp/news/a04TL00001WlLPTYA3)ことを、それぞれ2026年10月8日に案内しています。全国銀行個人信用情報センターも、通常より相当の日数がかかるとしています。
:::

本人申告とあわせて、次のことも設定しておくと、気づくまでの時間を短くできます。

- 自分の信用情報を[開示請求](https://www.cic.co.jp/mydata/)して、登録内容を確かめる。開示報告書には、契約の内容に加えて、会社が審査のために照会した申し込みの記録も載るので、覚えのないものがないかを見られます
- クレジットカードと銀行口座の利用通知を、1件ごとにすぐ届く設定にする
- オンラインの支払いには、バーチャルカードや、利用上限を低く設定したカードを使う

運転免許証については、紛失していなくても、今回の流出の対象になった可能性がある人に再交付を認める県が出ていると[報じられています](https://news.livedoor.com/article/detail/32512864/)。対応は県ごとに異なるので、お住まいの都道府県の運転免許センターや警察署に、事前に確認してみてください。

:::message
免許証を再交付しても、番号のすべてが変わるわけではなく、すでに流出した画像が消えるわけでもありません。「これをすれば完璧」という対策はないので、できることをいくつか重ねておく、という考え方が合っていると思います。
:::

| 1. 退会で終わらせず、消去まで依頼する | 高 | ★★☆ | 預けている情報を減らす | 使っていないサービス1つに消去を依頼する |
| 2. パスワードマネージャーの自動入力で、偽サイトに気づく | 高 | ★☆☆ | 便乗したフィッシングを防ぐ | ログインを自動入力に統一する |
| 3. 流出を通知で受け取れるようにする | 高 | ★☆☆ | 気づくまでの時間を短くする | Have I Been Pwned の通知に登録する |
